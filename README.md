# UnlockR7

Утилита для принудительного удаления «фантомных» файлов блокировки, которые Р7-Офис оставляет после аварийного завершения (зависания, вылета, сбоя питания). Работает с локальными и сетевыми папками, не требует установки.

## Проблема

Р7-Офис (как и многие офисные пакеты) создаёт временные файлы блокировки:

- `~$имя_файла.расширение`
- `.~lock.имя_файла.расширение#`

После некорректного завершения процесса эти файлы остаются, и при следующем открытии документа Р7-Офис выдаёт сообщение «Файл уже открыт другим пользователем». Очистка вручную через Проводник часто невозможна из-за занятости файла процессом или недостаточных прав.

## Что делает программа

- Завершает все запущенные процессы Р7-Офис (`r7*`).
- Ищет файлы блокировки, соответствующие указанному файлу (или группе файлов), включая варианты с обрезанными именами (Р7-Офис иногда укорачивает имя до ~8 символов).
- Если в список добавлен сам файл блокировки (например, `~$Отчёт.xlsx`), удаляет его напрямую.
- Использует несколько методов удаления: `os.remove`, PowerShell, переименование, `cmd del` – пока файл не будет удалён или не станет ясно, что это невозможно.
- Всё выполняется без мелькания окон командной строки.

## Как использовать

1. **Запустите `UnlockR7.exe`** (или `python R7-Unlocker.py`, если у вас есть Python).
2. Добавьте файлы в список:
   - **Добавить файл** – выбрать один или несколько файлов (можно оригиналы, можно сами блокировки).
   - **Добавить папку** – программа просканирует выбранную папку и все подпапки, найдёт все файлы, начинающиеся с `~$` или `.~lock.`, и добавит их в список.
   - **Перетащите** файлы или папки прямо в окно (если установлен модуль `tkinterdnd2`).
   - Можно **редактировать список вручную** – вставлять пути, удалять строки, править.
3. Нажмите **«Разблокировать»**.
4. Программа завершит процессы Р7-Офис, найдёт и удалит все связанные блокировочные файлы.
5. По окончании покажет отчёт – что удалось, что нет.

**Горячие клавиши:**
- `Ctrl+O` – добавить файлы
- `Ctrl+F` – добавить папку
- `Ctrl+U` – разблокировать
- `Esc` – выход
